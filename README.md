# 《重生成合欢宗大师姐以后，我成了万人迷？！》

女性向 · 修仙重生 · 万人迷恋爱 · 文字冒险游戏（BG / 纯网页）

前世，你是灵药宗丹道第一人"玉露仙子"聂霜月。纯阴之体泄露那日，未婚夫夏家为攀附魔渊，亲手把你装进囚灵车。
师门沉默，众人避让——寒潭三年，你元神俱损而亡。

再睁眼，你重生在合欢宗大师姐身上，距离那场灭顶之灾，还有三年。

这一世你本想断情绝爱、专心大道……可为什么那五个人，一个接一个地围了上来？

## 玩法

- **点击对话框**推进剧情。
- **点击画面空白处**可隐藏文字 UI，欣赏完整人物立绘 + 场景背景，**再次点击恢复**。
- 场景自动切换背景图；立绘随出场角色切换，全程保持人物外观一致。
- 好感度**隐藏结算**（不直接显示数值），不同选择导向不同结局。
- 顶部菜单：`存档` / `标题` / `好感` / `♪音乐`。
- **程序化古风 BGM**：以 WebAudio 实时生成的五声音阶氛围音乐，无需外部音频文件，可随时开关。
- 含 **R18 剧情**，进入前需通过 18+ 确认；也可选择「跳过本章」进入非 explicit 的纯洁版本，不影响主线。
